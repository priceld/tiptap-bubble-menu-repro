BubbleMenu: a stale preventHide strands the menu on screen

Steps

  1. Select some text in the editor. The bubble menu appears.
  2. Click Button A in the menu. Focus moves into the menu and the menu stays open. This is correct: mousedown set preventHide, and the blur it caused consumed the flag.
  3. Click Button B in the menu. The editor is already blurred, so this mousedown sets preventHide again with no blur to consume it. The flag is now stale.
  4. Press Escape. Focus returns to the editor with the selection intact, and the menu stays open.
  5. Click the dashed area below.

Expected: the menu hides, as it does without steps 2–4.
Actual: the menu stays visible. The log records no hide.

Control: reload and do steps 1 and 5 only. The menu hides correctly, which isolates the stale flag as the cause.
